# 星轨实验室 · V3 验收指南

这是原生 Room v3 / 作者 API 1 的离线 HTML 作品，属于 V3-INTEGRATION-001 Task3。源码在 rooms/v3-orbit-lab；共享 SDK 为当前 creator-kit/v3/sdk 的复制件。独立打开 index.html 可看外观并点三页预览；系统读数、应用启动、Core 切页和生命周期须在 Dext 运行，浏览器预览不算通过。

## 打开
1. 在配置器“使用”页选择“导入”，选交付的 v3-orbit-lab.zip，打开新作品，再应用。
2. 首次应用只自动启用导航。编辑页“按钮与本机设置”选“我的应用”，选择已有 ChatGPT 目标并保存本机设置。作品不携带程序路径或私人绑定。
3. Room编辑页独立“本机数据授权”区的“数据授权来源”选择“Widget · 轨道观测台”，勾选时间、硬件、媒体和音量；其对应component.observatory的真实读取。未授权显示横线，不用模拟值填充；普通小窗口或配置器取得焦点不会停止读数；实际壁纸暂停或锁屏时才停止。

## 第一组：持续内容、切页和统一按钮
- 点击 Dock 三个 Desk/上一页/下一页，确认三个名字与三种星球画面对应；连续下一页按星轨→信号→静谧→星轨顺序，上一页相反。本作品采用650ms渐变转场。
- 点击 Widget“记录 & 下一页”，看计数增加。多次往返后，左侧 INSTANCE 与 Widget 末尾实例编号不变，计数和运行时长不重置；三 Desk 的 Widget 标题/编号分别为轨道01、信号02、静谧03。
- “信号”Desk 有两个图标和 Dock 的“我的应用”，共用同一个按钮。设置一个本机目标后都应打开该目标；换肤只改变普通图标。
- 切其他窗口再返回桌面重复点击，标题占用区、Widget 和 Dock 不遮住可操作图标。拖动略过。

## 第二组：真实读数与授权
- 给 Widget 允许时间/硬件/媒体/音量读取；回桌面看读数，与系统时钟、任务管理器、系统音量、正在播放的标题比较。
- 撤销其中一项后，对应读数消失，外框及其他读数保留。恢复允许后重新读取。
- 有效读数仍取决于 Windows 来源：没有媒体播放会话时显示“没有系统媒体会话”，不是失败。
- 在同一区域勾选“读取本机记忆”和“保存本机记忆”。脚本仅在两项都 available 时读回/保存计数；等待“已保存”后正常退出/重启，再核对读回。只开一项或显示“待授权”时，本次文档计数不代表重启保存成功。撤销不删除已有记录，作品分享不携带个人计数或授权；完整人工验收仍待统一确认。

## 第三组：生命周期与恢复
- 首次建立 Player 有约1.2秒的“正在对齐星轨”启动页，切 Desk 不重播。暂停时启动预算和持续动画停止，恢复继续。
- 通过现有闲置/屏保入口进入待机，有单独“星轨仍在，暂且休息”页面，移动鼠标返回原 Desk。
- 在非首 Desk 正常退出/启动 Core，确认恢复原 Desk；新的文档实例编号会变化，这是正常重建。浏览器独立预览不能证明这些功能。

## 第四组：Dock、分享和试验台
- 打开试验台，切 Desk/不同尺寸/暂停，查看按钮区域和占用提示；试验台的数据是模拟示例，单独验收真实桌面读数。
- 设置 Dock 自动隐藏或常驻：触边能显示和点击，最大化/全屏退出后工作区与任务栏恢复。该模式是本机偏好，不由作品偷偷切换。
- 另存为新作品、导出 zip 再导入，确认新副本独立身份、资源齐全；绑定和授权按当前复制/分享规则处理，zip 不包含私人路径或 KV。
- 图片/视频/GIF逐类创建导入、未知版本/兼容提示、系统锁屏/DPI/Explorer及异常恢复仍需其他素材/系统操作，本 HTML 样包不宣称覆盖它们。
