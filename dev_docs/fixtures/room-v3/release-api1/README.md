# 首发 API 1 冻结样包
这是发布前候选基线，不表示六类作品已完成Windows验收。只能复制到临时库或导出后导入，不直接编辑本目录。
image/video/gif/html覆盖四类背景和官方默认导航/待绑定入口；continuous覆盖持续作者场景、共享仪表盘和作者转场；dock覆盖共享/Desk差异/无Dock返回。
所有作品为version3/apiVersion1，每次正式导入生成独立Room UUID；目录外的catalog.json固定原始作者字节摘要。没有安装记录、源路径或私人配置。
视频/GIF为本仓库生成的几何色块（单线程、1秒小素材），图片及网页为Dext样例；持续场景/Dock按仓库现有作者模板冻结，SDK版权沿原文件。
升级门槛见dev_docs/acceptance/V3-P10-002-release-samples.md和dev_docs/RELEASE_V3_COMPATIBILITY.md。第一次通过真实全链后才记录发布资格；以后程序发布前保留并回归这些原始样包。
