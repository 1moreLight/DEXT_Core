# 原生 Dock 样包

可从配置器打开的完整Room v3源目录，不是预制安装副本；正常应用生成安装身份/摘要。HTML/CSS/JS/当前SDK与SVG均自包含，不联网。

## 使用（游戏结束后）

复制整个目录到自己的Room库，在配置器打开副本的room.json，保存并应用，设置页开启Dock自动隐藏。当前工作分支未构建/运行，样包不代表Windows行为已验收。

- 共享页：三栏CPU/时间/GPU，上一页、个人应用、下一页。
- 本页差异：引用同一shared-dock，仅覆盖森林配色和右栏时间。前两页应保持同一作者文档和Dock Player；编辑器重置右栏后恢复GPU。
- 无Dock页：不引用Dock，原任务栏应恢复；桌面“返回Dock”/“回到共享页”可返回，离开本页恢复单个Dock。
- 只读数据须在本机面板明确授权，缺授权隐藏读数；个人应用初始未绑定，在本机按钮面板配置。私人目标不写入样包。
- 模板参数/区域/稳定按钮可在编辑器修改；全局高度设置应显示实际DIP/DPI/受限提示，屏幕限制不改保存偏好。

作者资源复用creator-kit/v3/dock-templates/three-panels和当前creator-kit/v3/sdk的原文件，保留自包含快照；以后更新模板/SDK时需同步。安装、原生输入、数据、共享文档、任务栏和故障恢复仍按V3-P8-001六项验收卡执行。本轮只有JSON/资源/快照核对。
