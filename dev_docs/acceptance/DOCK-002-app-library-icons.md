- 分支：`feat/dock-002-app-library-icons`

- 目标：在具体 Room 的 DockEditor 中搜索现有应用库，把真实应用加入全局或当前 Desk Dock，并通过现有 Room 保存链保留图标和启动信息。
- 范围外：桌面图标拖入 Dock、Player/Core 桌面编辑 IPC、运行态圆点、应用库扫描/清理规则、Dock 模板与创意工坊。

## 自动检查

- [x] `cd tauri-ui && npm run build`：React/TypeScript 生产构建通过。
- [x] UI 设计模式：浅色和深色下，应用搜索、作用域选择、应用卡片与已选列表均可读、无溢出；搜索、去重、切 Desk、桌级覆盖和恢复全局交互通过。

## 人工验收

1. [ ] 启动桌面配置器，进入“编辑”，打开一个具体 Room，并展开“当前 Room Dock 参数”；可看到“常驻应用”区域、搜索框以及“全局 Dock / 当前 Desk”作用域。
2. [ ] 选择“全局 Dock”，搜索并加入一个真实应用；该应用显示真实图标，切换 Desk 后仍属于全局 Dock，重复点击不会产生重复项。
3. [ ] 选择“当前 Desk”，加入另一个应用；它只写入当前 Desk 的覆盖列表，切换到其他 Desk 不会错误加入同一个桌级列表。
4. [ ] 点击 Room 的保存操作后关闭并重新打开该 Room；两个作用域中的应用仍存在，`room.json` 中保留应用名称、`icon_png` 和 `launch.target/args/workdir`。
5. [ ] 应用或预览该 Room；Dock 显示真图标，双击新增的 Dock 应用时按保存的启动信息打开对应程序。
6. [ ] 从两个作用域各移除一个应用并再次保存、重开；对应项保持删除，其他 Dock 设置和图标不受影响。

## 通过标准

- 所有必选项通过；全局与桌级作用域无串写，真实图标和启动信息完整持久化，没有阻断问题。
