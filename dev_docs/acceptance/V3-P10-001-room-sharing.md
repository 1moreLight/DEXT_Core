2. 本机绑定/皮肤跟随另存或库复制；新旧副本编辑互不影响，不继承授权、KV或个人布局；Core断开/保存失败有明确反馈且不冒报完整副本成功。

4. 同一zip导入两次形成独立Room UUID，名称冲突可换名；外观和作者默认动作/节点保持，私人入口待绑定，未知格式或缺资源明确失败。
5. 导入副本打开/预览/应用/切页/普通重启后资源与身份一致；资源/区域问题可定位，不自动覆盖现有Room。
6. 删除副本清该Room个人数据且保留全局目标与其他Room；失败保持可恢复状态。恢复原数据，集中整体审查。
