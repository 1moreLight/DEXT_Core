## 人工验收

1. [ ] 在 `tauri-ui` 执行 `npm run dev:ui`，打开配置器设计模式，进入“编辑”→“Room”→任一 Room 的“编辑”。
2. [ ] 依次选中启动画面和不同 Desk，在下方属性栏把名称改成短名称、较长名称；确认节点随内容变化后互不重叠，每条箭头仍准确贴在对应节点边缘。
3. [ ] 检查相邻 Desk 的双向连线：两条线路方向可辨，switch 标记保持在对应线路之间，不压住节点或箭头。
4. [ ] 调整浏览器窗口宽度和高度，并拖动上下分区分隔条；确认布局与连线会自动重算，没有旧位置残影或断线。
5. [ ] 切换浅色/深色主题，确认节点、连线、箭头和 switch 标记均清晰可见。
6. [ ] 点击“撤回”左侧的“新增 Desk”，确认新节点立即出现，并与上一 Desk 自动生成清晰的双向连线。
7. [ ] 选中“启动画面”，在属性栏切换目标 Desk；确认启动画面始终只有一条出线，且立即改连到所选 Desk。
8. [ ] 对新增 Desk 和启动目标选择执行撤回、重做，确认节点与连线一起恢复。
9. [ ] 使用 3 个以上 Desk，确认每个 Desk 均有上一个和下一个邻居；相邻 Desk 的双向线连接节点顶部/底部，switch 位于两节点之间。
10. [ ] 确认只有第一个与最后一个 Desk 的双向环线走右侧；增加第四个 Desk 后，原首尾线自动改为“第一个 ↔ 新末 Desk”。
11. [ ] 使用 2 个 Desk 时确认只显示一组双向 switch，不重复生成首尾环线；1 个 Desk 时不显示 switch。
