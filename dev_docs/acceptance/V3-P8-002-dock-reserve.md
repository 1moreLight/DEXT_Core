## 人工步骤（游戏后集中）
1. 保护原数据后build.ps1→start.ps1，打开native-dock样包；设置常驻/高度，重开Core和配置器保持，切Room不覆盖全局偏好。
2. 普通软件最大化避让Dock，实际高度/DPI和占位确认匹配；单个Dock非激活鼠标/明确键盘可用，共享页与Desk差异正确。
3. 自动隐藏↔常驻、调整高度重复切换，先释放旧窗口/占位再建新宿主；没有累积空白或第二Dock，保存失败保持已确认值。
4. 主屏DPI/分辨率和原任务栏设置改变、Explorer重启后重新协商实际矩形/工作区；不覆盖其他系统栏的占位。
5. 全屏游戏/Alt-Tab/锁屏恢复，Dock隐藏不遮挡、不夺焦点；恢复后可见性/原工作区策略正确。
6. 无Dock页/禁用/正常退出，以及Core/Player/看护故障恢复，原任务栏和工作区恢复且无残留窗口；原数据恢复，集中整体审查。
