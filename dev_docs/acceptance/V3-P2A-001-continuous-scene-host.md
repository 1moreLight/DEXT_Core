# V3-P2A-001 连续场景宿主验证

- 状态：开发中
- 分支：`feat/V3-P2A-001-continuous-scene-host`（基于 V3-CORE-004）
- 目标：真实桌面 Player 中，一个持续 HTML 场景跨 Desk 切换保持同一文档与运行状态，官方图标可操作，作者声明占用区和图标/Widget 使用同一坐标系。
- 范围外：P3 正式作品 Schema、开放生产 v3 会话准入、Core/Player 正式传输、原生 Dock/AppBar。

## 人工验收

1. 在测试 Room 的持续 HTML 场景内观察计数器，使用 Dock 上一页/下一页反复切换；计数不归零、场景不闪烁。
2. 在作者互动区域操作按钮，官方图标双击和编辑拖动仍生效；无占用的空白区域可透传输入。
3. 调整显示缩放或窗口尺寸，核对占用区和图标/Widget 的相对位置；记录偏差。
4. 在真实 WorkerW Player 重复以上步骤，并运行 `scripts/verify-runtime-identity.ps1` 核对运行来源。

## 通过标准

自动检查和上述实机步骤有可复现证据；本包的验证接口不冒充最终作品协议。
