## 人工步骤（最终集中）
1. 新建两Desk Room，选择三栏/导航模板；自动显示作者区域及公开参数，不手画坐标；保存重开保留选择。
2. 共享左栏CPU/中栏时间/右栏GPU，Desk2只将左栏改倒计时；改共享右栏后两Desk未覆盖项一起变，重置左栏差异恢复继承。
3. 改作者默认导航/待绑定按钮，Desk引用与导航连线分开；保存重开、改名/排序、撤销重做后ID和关系保持；真实按钮区域与默认操作对应。
4. 删除一个区域或Dock引用，差异和悬空引用有明确结果，其他图标/组件引用与个人目标不串位；重建不复用已删除按钮ID。
5. 允许当前模板所选只读数据后实际显示，撤销/缺数据保持静态外框并隐藏读数；编辑侧提示原因，授权不写进作者Room。
6. 应用切页、缩放与普通重启，共享实例/有效配置/按钮几何正确；失败导入/保存保原作品，结束正常退出。
