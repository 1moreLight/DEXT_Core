## 人工验收

1. 启动本分支配置器，在“使用”页点击当前 Room 的“编辑”；应立即进入编辑页，不再无响应。
2. 编辑页顶部应明确列出 `widgets/clock-hardware/*` 未声明资源，并说明保存、预览、应用、导出暂不可用。
3. 点击“移至恢复目录并继续”；界面显示恢复目录，Room 原目录的孤儿文件消失，恢复目录中保留 `widgets/clock-hardware/*` 结构。
4. 修复后编辑、保存和预览恢复；重新打开同一 Room 不再显示警告。
5. 人为制造缺失的已声明 Widget 入口文件后再点编辑；应留在原页并显示具体错误，不能进入半初始化编辑状态。
6. 确认当前真实桌面、五项图标偏好和 Widget 不因本包发生变化。
