## 人工验收

1. [ ] 默认偏好下向当前 Room 加应用，无需保存/应用，配置器最小化，桌面切到目标 Desk、进入编辑并高亮新图标，可立即拖动。
2. [ ] 关闭“放入应用后前往桌面编辑”，连续加入多个应用；真实桌面实时更新，但配置器和选择器保持打开。
3. [ ] 编辑非当前 Room以及 Core 断线时，不错误最小化；草稿保留并显示明确提示。
4. [ ] 在稀疏和成组布局中新增应用，图标靠近现有图标组且不覆盖图标、Widget 或 Dock。
5. [ ] 在真实桌面移动和缩放 Widget；冲突图标拖动中只预览，松手后移动到最近安全格，未冲突图标不动。
6. [ ] 制造没有足够空位的布局；Widget 与图标整体恢复原位，并出现空间不足提示。
7. [ ] 返回配置器后看到桌面更新的图标坐标和 Widget placement；此前未保存的背景/转场等草稿仍保留。
8. [ ] 重启后布局保持；DockEditor、Dock 双击启动/运行圆点、Desk 切换和 Widget 内容不回归。
