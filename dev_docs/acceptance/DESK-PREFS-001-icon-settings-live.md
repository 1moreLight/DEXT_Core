## 人工验收（代码提交后，在真实 WebView2 桌面）

1. [ ] 在设置中依次切换图标光晕/紧凑内容框/无边框，并切换图形小/标准/大；观察当前真实图标立即变样、图形居中，Widget/Scene 不重载。
2. [ ] 打开/关闭名称，检查单行省略、隐藏后悬停约 500ms 的完整名称浮层，以及编辑/按下/拖动时浮层不出现。
3. [ ] 切换命中框小/标准/大及紧凑/标准/宽松间距；点击框内图形和可见文字有反应，框外网格空白不启动应用也不拖动，框宽/高同档统一且与图形同中心。
4. [ ] 在已有图标较密集的 Room 改大间距或命中框：合法图标不乱动，冲突图标才移动，不与 Widget/Dock 重叠；在无可用格时保持原布局并提示，重启后不出现半次搬格。改回小档不自动回到旧坐标。
5. [ ] 通过配置器给当前 Desk 新增应用，检查新图标即时可见且与当前偏好网格一致，不与已有图标/Widget/Dock 重叠；切 Desk、重铺和重启后五项偏好与最终图标位置保持。
6. [ ] 长按进入编辑并松手，再次按住图标连续至少十次拖放：每次都在 pointerup 前跟随指针且松手后正确持久化；取消、快速移动、空白双击退出及 Widget 拖动/缩放仍正常。
7. [ ] 开启 Windows reduced-motion，确认装饰抖动/缩放/过渡关闭，但点击、命中、实际拖动位移和布局提交仍然可用。
8. [ ] 当当前桌面未运行时修改偏好，确认 UI 只提示下次加载生效；桌面运行时 UI 仅称“已发送”，不谎称已经渲染；重载后快照正确。
