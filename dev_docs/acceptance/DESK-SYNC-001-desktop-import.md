# DESK-SYNC-001 独立验收

状态：开做，实施0/4=0%。
目标：一个Desk一键接入用户/公共Windows桌面真实文件并正常打开。
范围外：自动监听、外部拖放、文件写操作、虚拟Shell项。

1. 选择一个Desk并一键接入，文件、文件夹、快捷方式显示真实名称和图标。
2. 用户与公共桌面同名不同项均保留；再次接入或手动刷新不产生重复。
3. 点击临时测试文件/目录/快捷方式能打开正确目标，原Dock与其他Desk点击保持正常；物理触控单独确认。
4. 关闭同步后源文件仍在Windows桌面，其他私人入口保留；重启后同步页与布局保持。
5. 分享Room不带本机文件路径、文件或同步配置。

临时夹具/自动检查不能冒充上述人工通过；用户统一验收前不合master。
