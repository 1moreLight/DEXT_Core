## 人工验收

1. [ ] 进入编辑 → Dock，模板详情主按钮显示“编辑”，不再出现“到 Room 中选择”。
2. [ ] 点击“编辑”：内置模板保存时生成本地副本；本地模板再次编辑能覆盖保存。
3. [ ] 点击“新建”，系统立即要求选择 Dock JSON 文件；取消选择不报错。
4. [ ] 导入合法 Dock v1 文件后出现一张“本地”卡片，关闭并重开配置器后仍存在；非法文件给出明确错误且不入库。
5. [ ] 在 Dock 模板库切换卡片只改变库内选中和详情，不修改任何 Room 的 `room.css`。
6. [ ] 进入编辑 → Room → 编辑具体 Room，已导入模板与内置模板都出现在“当前 Room Dock”选择区。
7. [ ] 为该 Room 选择任一 Dock 后，当前 Room 的 `room.css` 更新；模板区块外作者 CSS 保留，预览立即变化。
8. [ ] 切换其他 Room 再返回，各 Room 的 Dock 选择互不串用。
