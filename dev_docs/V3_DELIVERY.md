1. V3-P3-001：正式清单、路径/资源校验、内容摘要安装快照、双语言一致性样包。
2. 绑定权限与持久个人覆盖，作者动作只接受宿主核验的输入。

4. 创建/节点/Dock模板与差异、统一按钮/皮肤、作者试验台，全部贯通v3契约。
5. P2b原生Dock输入与AppBar实验，再接两种Dock产品模式和恢复看护。
6. 分享/另存/删除个人数据、首发样包库、Release及性能与全链验收。
