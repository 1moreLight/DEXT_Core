# V3-P8-008 应用 Dock 自动隐藏
目标：应用 Dock 可选择自动隐藏；底边唤出，按下/菜单/预览期间不隐藏，跟随 Dock 时由已有看护接管任务栏。
范围外：AppBar 工作区占位、多屏扩展、HTML 换肤、重写触控、合并 master。
01 状态策略开做；02 窗口与设置待做；03 构建运行待做；04 交接待做。0/4。
默认保持常显，只有用户选择后才自动隐藏。全屏/锁屏隐藏；退出恢复。复用现有 500ms 应用枚举，独立轻量可见性定时器不重建按钮。
接口：策略输出 visible；窗口在原控件上 Show/Hide；服务续租任务栏并在交接前确认释放；配置器添加持久化模式。任务栏“恢复”保持最高优先。
风险：按下中隐藏、预览跨窗隐藏、全屏抢焦点、旧任务栏租约未释放即交给主题。对应定向检查，不扩安全测试。
