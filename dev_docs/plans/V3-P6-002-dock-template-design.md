# V3-P6-002 Dock模板与交互设计

## 用户目标与依据
按V3_PLAN §5/§5.1/§6.2条目8和PROJECT的D05/D06确认规则：选Dock造型即可得到作者区域，分别配置展示数据/按钮；共享配置复用到Desk，某Desk只覆盖改动字段，删除差异恢复继承；名称/顺序不改变身份。用户已授权按完整路线连续开发、最终集中验收，本包沿用本会话Native执行，不另设中途确认。
这是跨作者文件、配置器与运行接口的架构任务。已有P6组件config和Desk componentOverrides、SDK config递归合并/数据/按钮/几何、Core只读数据服务可复用。

## 选择的实现
1. 用自包含原生HTML模板和独立formatVersion1描述文件。区域有稳定语义ID、展示/按钮类别、作者示例、公开参数；卡片不执行任意元数据代码。提供三栏仪表和导航条两款起始模板，并允许带描述文件的本地HTML导入。模板选择复制完整HTML/CSS/JS/描述及当前SDK进Room资源清单。
2. 组件config保存公开模板选择、参数、启用区域、数据选择和按钮语义引用；Desk componentOverrides只存差异叶子，保持既有SDK对象递归继承/null显式覆盖/数组整体替换。作者描述不限定槽只能接百分比/文字等类型；time/hardware/media/audio当前全部已开放只读源均可选，HTML解释数据路径与显示方式。
3. 替换外观保留同名区域的稳定buttonId与组件ID；移除区域清理其共享/Desk差异及不再被其他图标/内容引用的作者按钮。不复用已删除按钮ID，不删除全局个人目标；个人目标绑定/皮肤UI归下一包。
4. 配置器显示“Dock外观→共享交互→Desk引用”，引用差异与导航连线分开；可改作者默认通用动作（上一页/下一页/转到Desk/待绑定/退出），私人覆盖仍归Core。HTML按实际DOM和resize发布按钮；Dock固定框占用按placement由官方宿主处理，occupied仍只属于roomScene，用户不画命中坐标。
5. 为真实数据展示补配置器只读授权控制：只有time.read/hardware.read/media.read/audio.read，Core保存当前安装戳/消费者授权并保留无关权限。页面声明不自动授权，失效安装不能续用授权；读取和编辑仅通过配置器RPC，作者SDK不新增权限编辑接口。UI可读回状态、明确允许/撤销，再由现有SDK能力刷新进入数据。time倒计时是作者明确配置的公开示例截止值/显示方式，私人待办/计时器数据另归个人呈现包。

## 备选与取舍
- 延用v2 dock/CSS快照会丢失原生组件、区域和版本边界，因此本包使用P6原生HTML组件。
- 增加Room顶层专有模板字段会引入双套契约；本包复用已正式支持的config/overrides，描述文件是作品资源。
- 仅做编辑mock不能验证数据运行；本包把有限只读授权接到实际Core，动作物理输入仍沿P5最终门槛。

## 失败和范围
失败导入/保存保留原作品；未知模板/缺区域给出定位信息，不猜绑。数据missing/denied/unsupported/error及明确渲染错误保留静态外框、隐藏读数；不把有效文字当作数据缺失。
范围外：桌面拖动、顶层Dock/AppBar、分享/另存、私人目标/皮肤编辑、在线模板市场。不会开展新增网络专项，只做模板/继承/数据/按钮所需功能回归。凭据宿主未解除时不操作Core OS桌面输入。
