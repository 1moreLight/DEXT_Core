## 一、目标

在一个工作包、一个分支和一次最终人工验收内，把现有配置器升级为唯一的 Room v2 创作与管理入口，并同步完成它所依赖的真实运行能力：保留现有设计语言和成熟交互，重构过度集中的 React 结构，接通 Scene 自由数据展示、多 Widget 布局、图标避让、可信系统热点、受控系统数据、安全分享、隔离预览和 AI 前端包创作闭环。

本工作包不提供中途合并或分阶段验收。内部可以按风险顺序开发、测试和提交，但只有全部通过最终验收后才进入 `master`。

## 二、已经确认的产品决策

1. Dext 只支持原生 Room v2；删除无用 demo、v1 兼容、迁移、降级和仅为旧格式存在的代码。
2. 保留当前配置器的视觉语言、Room 卡片、使用/编辑/设置概念、Desk 思维导图和已经验证的业务能力；重构对象主要是代码职责和编辑器信息架构，不是无理由换皮。
3. Scene 和 Widget 同时存在：
   - Scene 允许作者或 AI 使用 HTML/CSS/Canvas 自由构图，把时钟、进度条、性能、媒体封面等嵌入画面具体位置；
   - Widget 是可复用、可多实例、可拖动、缩放、层叠和单独配置的受管内容；
   - 不把所有动态内容强制做成大小不一的卡片。
4. 一个 Desk 可以有多个 Widget。Widget 允许彼此重叠；宿主管理位置、尺寸和 z。
5. Widget 遮挡桌面图标时，松手后由官方宿主稳定地把图标移动到最近合法网格；整次调整可撤销。
6. Scene/Widget 不能直接执行系统命令。只读数据和系统动作均走版本化、白名单、限频、可审阅的 Dext 能力桥。
7. 系统动作首批只包括已确认的媒体与 Windows 主音量能力；不存在任意 Shell、PowerShell、可执行路径、文件路径、URL 或通用命令字符串。
8. 分享包携带能力声明但不携带本机授权；导入后必须重新确认。
9. AI 创作以标准模板、Schema、能力清单、校验器和隔离预览为边界。本工作包不内置某家模型服务或账号系统。

## 三、范围内结果

### 3.1 配置器信息架构

- **空间库**：本地 Room 搜索、排序、选择、应用、重新应用、复制、重命名、删除、导入、导出和安全校验；当前使用状态来自真实 Core，而不是前端猜测。
- **空间编辑器**：统一顶栏、Room 层级树、真实比例桌面画布、属性/数据/权限检查器，以及可切换的 Desk 流程视图。
- **运行与诊断**：Core/Player 连接、当前运行 Room、能力状态、日志与安全错误入口。
- **设置**：只呈现真实可持久化的设置。
- 现有空白“创意工坊”不再作为孤立一级页面；未来在线内容是空间库的数据来源之一。

### 3.2 编辑器布局与交互

```text
┌ 返回 / Room 名称 / 撤销重做 / 保存 / 预览 / 应用 ┐
├──────────────┬────────────────────────┬────────────────┤
│ Room 层级树   │ 画布 / Desk 流程视图   │ 属性/数据/权限 │
│ Desk          │                        │                │
│ Scene         │ 真实桌面比例与安全区   │ 内容、位置     │
│ Icons         │                        │ 绑定、动作     │
│ Widgets       │                        │ 授权、错误     │
│ Dock          │                        │                │
└──────────────┴────────────────────────┴────────────────┘
```

- 画布使用 1920×1080 逻辑坐标，按 `contain` 映射到实际区域。
- 支持选择、多选、拖动、缩放、层级、吸附、对齐、安全区和冲突提示。
- 流程视图只负责 start、idle、Desk 顺序、startDesk 和有向 switch；排序必须按 Desk 身份重映射关系，不能按旧数组索引误配。
- Dock 在真实画布中可见并参与安全区计算；全局值和每 Desk 覆盖仍可编辑。
- 所有删除、替换、重命名、忙碌、失败和未保存状态都有明确反馈。
- 撤销/重做覆盖 Desk、Scene、图标、Widget、Dock、热点与避让事务，并可在配置器重启后恢复当前草稿历史。

### 3.3 React/Tauri 结构

当前 `tauri-ui/src/App.tsx` 约 2784 行并集中 40 多组状态。目标结构应让 `App.tsx` 只装配应用，不再保存所有页面和编辑逻辑。推荐边界如下，最终命名可按代码事实调整：

```text
src/
  app/                 应用壳、导航、错误边界
  pages/               Library / Editor / Runtime / Settings
  editor/              hierarchy / canvas / inspector / desk-flow
  features/            rooms / desks / scenes / icons / widgets / dock
  runtime/             Tauri commands、预览协议、能力类型
  store/               单一编辑草稿、选择、历史和派生 selector
```

- 迁移现有已验证逻辑，不复制一套长期并存的旧应用。
- Room/Desk/Dock 状态只有一个真相源；禁止父组件、子组件和本地草稿多份双写。
- 消除 `DockEditor` 的 `any[]` 等临时类型，让 UI 使用 v2 契约生成或共享的明确类型。
- 纯算法与 DOM/Tauri 分离：Desk 重排、switch 重映射、坐标映射、图标避让、权限归一化和历史事务均写成可测试纯函数。
- 保留浏览器 `dev:ui` mock 模式，但所有真实按钮必须另有 Tauri/文件系统/真桌面验证，不能以 mock 成功代替端到端结果。

### 3.4 Scene 自由展示

- Scene HTML 固定在沙箱中运行，不获得 Tauri、gRPC、文件系统或宿主 WebView 接口。
- 提供版本化 Scene SDK/声明方式，把结构化只读数据送入 Scene；至少覆盖：
  - 本地时间、语言、视口、当前 Desk 和暂停状态；
  - CPU、GPU、RAM 摘要；
  - Lively/Dext 音频频谱；
  - 当前系统媒体标题、作者、播放状态和可用时的封面；
  - Windows 默认输出主音量和静音状态。
- 作者自由决定数据如何呈现。配置器只负责内容选择、声明审阅、热点布局、安全预览和错误反馈，不尝试成为任意 DOM 的通用低代码网页设计器。
- 生命周期覆盖 background、start、switch、idle；切 Desk、替换 Room、暂停和销毁后不得遗留订阅或计时器。

### 3.5 WidgetHost

- 每 Desk 支持契约允许数量的 Widget，多实例 id 在 Room 内唯一。
- 每个 Widget 使用官方容器和独立 `sandbox="allow-scripts"` iframe，不加 `allow-same-origin`。
- 官方容器管理 placement、z、拖动、缩放、编辑柄、焦点、错误与卸载；Widget 内部 z-index 不能逃出实例矩形。
- 实例通信校验 `event.source`、协议版本、instanceId、消息大小、字段和能力；旧实例 token 在卸载后立即失效。
- 单个 Widget 崩溃、超额或发送非法消息时只隔离该实例。
- 配置器预览和真实 Player 复用同一宿主协议与权限默认值，不维护弱化的假实现。

### 3.6 图标避让

- 输入为 Desk 图标、Widget 矩形、逻辑网格、Dock/视口保留区，输出为稳定的新图标坐标；算法必须是可测试纯函数。
- Widget 拖动/缩放过程中只显示避让预览，`pointerup` 后一次提交。
- 选择最近合法网格，结果不得进入视口外、Dock、安全区或其他阻挡 Widget。
- 无合法位置时不丢失或覆盖图标，保持原位并提示冲突。
- 同一输入重复计算结果一致；整次避让与 Widget placement 变更属于一个撤销事务。

### 3.7 可信热点和系统能力

- Scene/Widget 只能声明矩形热点与固定 action id；作者 DOM 不直接获得系统动作函数。
- 官方透明命中层接收真实 pointer/keyboard 激活，验证当前 Room、实例、权限、参数和用户手势后调用封闭接口。
- 动作至少覆盖：播放、暂停、播放/暂停切换、上一首、下一首、0..1 主音量设置和静音。
- 只读能力逐实例订阅、限频、裁剪和暂停；敏感或不可用字段返回明确状态，不泄露本机路径。
- 默认禁止 Widget/Scene 直连网络、远程 iframe、下载、弹窗、顶层导航和任意协议跳转。本工作包完成离线安全边界，不实现 Dext 代理联网服务。

### 3.8 分享与 AI 创作闭环

- Room v2 zip 导入/导出必须包含声明资源、Widget manifest、Scene/Widget 内容与权限清单，并拒绝路径穿越、符号链接/重解析点、越界大小、未知版本、未声明文件和非法能力。
- 失败操作事务回滚，不留下半个 Room；重名处理可预测。
- 导出不写入运行包 `__source`、本机授权、缓存、媒体封面、系统信息、日志、草稿历史或绝对路径。
- 提供版本化 Scene/Widget 模板、SDK 类型、正反 fixtures、AI 创作提示词和本地校验命令。
- 配置器提供 AI 创作入口：导出当前创作上下文/提示词，导入生成包，展示 Schema、资源和权限报告，隔离预览后由用户确认写入。
- 不在本工作包内接入外部模型 API、账号、计费、云端创意工坊或任意自动上传。

### 3.9 清理

- 删除只为 v1、废弃 demo、旧页面副本、死状态、无消费者按钮和无用 Tauri command 存在的代码。
- 不为“可能以后需要”保留第二套编辑器入口。
- 不修改主 worktree 中用户未提交的 `rooms/`；测试使用独立 fixture/临时目录，真桌面验收只在明确步骤中执行。
