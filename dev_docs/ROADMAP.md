## 二、状态与完成定义

正常流转状态是 `排队 → 下一项 → 开发中 → 待验收 → 已完成`；无法继续时用 `受阻`。历史上已经终止的路线可标 `已暂停` 或 `已取消`，它们不占用唯一“开发中/下一项”名额，恢复时必须重新确认工作包范围。

工作包只有同时满足以下条件，才能标“已完成”：

1. 目标范围内的代码或文档完成。
2. 自动检查通过并已提交到独立分支。
3. 独立验收文件存在，对话中用户明确确认通过。
4. 分支已合并 master。
5. 对应 worktree 和已合并分支已清理。

只写完代码叫“待验收”，不能叫完成。

历史上出现过用户明确授权的流程例外：UI-V2-001 直接合并并豁免逐项人工验收，WIDGET-DRAG-001 直接在 master 开发后真机验收。验收卡必须如实记录这些例外，不能补写成按标准流程逐项执行；OPS-004 之后的新工作继续遵守标准流程。
